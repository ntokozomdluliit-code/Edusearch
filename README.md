# 📚 EduResearch Hub - Student Assignment Research Platform

A production-ready web application that helps students research assignments across all education levels (K-12 to PhD). The platform searches the web in real-time and provides curated, education-level appropriate answers with proper source citations.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-web-lightgrey)

## 🌟 Features

- **Real-time Web Search** - Uses Tavily API to fetch current, relevant information from across the internet
- **Education Level Adaptation** - Content complexity automatically adjusts for:
  - 🎨 Elementary School (K-5)
  - 📖 Middle School (6-8)
  - 🎓 High School (9-12)
  - 🏛️ Undergraduate
  - 🔬 Graduate/PhD
- **AI-Powered Summaries** - Generates clear, concise answers from search results
- **Source Citations** - Every answer includes clickable references to original sources
- **User-Friendly Interface** - Modern, responsive design that works on desktop and mobile
- **Privacy Focused** - API keys stored locally in your browser, never on a server
